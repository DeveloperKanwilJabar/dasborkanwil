Mekanisme Data Registry
  1. Create registry = create identitas registry + draft version + schema field awal.
  2. Schema field ini jadi referensi kolom untuk entry manual, mapping Excel, validasi, dan materialisasi record.
  3. Data yang masuk tidak langsung jadi record final; dia masuk dulu sebagai batch staging supaya bisa divalidasi dan diaudit.
Tidak perlu hardcode JSON line per row. Yang disimpan sebagai kontrak adalah schema_json.fields + mapping_spec di level version, lalu setiap row/record final tetap boleh punya payload JSONB untuk kebutuhan fleksibel.
